# Модель веток RevMap

Два независимых рабочих потока над одним проектом. Общий контекст и данные,
полный обмен информацией — но правки не мешают друг другу.

## Ветки

| Ветка | Ведёт | О чём | Рабочая папка |
|-------|-------|-------|---------------|
| `main` | оба | **общий канон**: контекст, данные, договорённости | `shared/` |
| `product` | Дмитрий (Дима) | продукт, а также маркетинг/стратегия со стороны продукта | `product/` |
| `marketing` | оператор (Иван) | стратегия, продажи, маркетинг, продвижение в каналах | `marketing/` |

## Правило «не мешать друг другу»

1. **Каждый пишет только в свою папку** (`product/` или `marketing/`).
   Разные пути → git-конфликтов между ветками не бывает.
2. **Общее — только в `shared/`** и только через `main`. Меняешь общий факт →
   правишь `shared/`, вливаешь в `main`, второй подтягивает `main` к себе.
3. **Обмен информацией — регулярный merge из `main`**:
   ```
   git checkout marketing && git merge main      # подтянуть общее к себе
   # ...работа в marketing/...
   git checkout main && git merge marketing       # отдать общее (только shared/)
   ```
4. Свои рабочие папки друг у друга **читаем свободно** (полный обмен), но
   **не редактируем** — предложения к чужой папке идут текстом/через main.

## Что где лежит

- `shared/context/` — паспорт проекта, вводные, договорённости (канон для обоих).
- `shared/data/` — общие данные, справочники, выгрузки.
- `product/` — материалы продуктового трека (Дима).
- `marketing/` — стратегия, продажи, маркетинг, каналы (Иван).
