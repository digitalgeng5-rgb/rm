# shared — общий канон RevMap

Единый источник правды для обоих треков (продукт и маркетинг). Живёт в `main`.
Меняется осознанно: правка здесь = правка через `main`, её видят оба.

- `context/` — паспорт проекта, вводные, договорённости.
- `data/` — общие данные, справочники, выгрузки.

> Правило: факта нет в `shared/` — он «нужно уточнить», а не «придумать».
