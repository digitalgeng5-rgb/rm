# sales — воронка и продажи

## pipeline.csv — единственный источник правды по деньгам

Одна строка = одно касание/сделка. Заполняет тот, кто ведёт продажи.

| Поле | Значения |
|---|---|
| `владелец` | Иван · Дима — **обязательно**, метрики считаются персонально |
| `стадия` | касание · ответ · демо · счёт · оплата · отказ |
| `пакет` | проба · годовой · агентский · планБ-услуга |
| `оплачено` | да / нет |
| `сумма_руб` | сумма счёта; для оплаченных — фактическая |

Из этого файла считаются все еженедельные метрики плана
([`../strategy/plan-300k.md`](../strategy/plan-300k.md), раздел 5) и принимаются
решения на гейтах. Чего нет в файле — того не было.
