# marketing — стратегия, продажи, продвижение (ведёт Иван)

Рабочий трек по стратегии проекта, продажам, маркетингу и продвижению в каналах.
Пишет сюда оператор на ветке `marketing`. Продуктовый трек читает, но не правит.

## Структура

| Папка | Что внутри |
|-------|------------|
| `strategy/` | стратегия проекта: позиционирование, цели, гипотезы, дорожная карта роста |
| `sales/` | продажи: воронка, скрипты, оффер, работа с возражениями, прайс/пакеты |
| `marketing/` | маркетинг: сегменты, JTBD, сообщения, контент-план, материалы |
| `channels/` | продвижение по каналам: Telegram, карты/локальный SEO, Директ, партнёрки и т.д. |

Общий контекст и данные — в `../shared/` (канон), подтягивается из `main`.
